# Code of conduct

Nod follows the Contributor Covenant, version 2.1. The full text is at <https://www.contributor-covenant.org/version/2/1/code_of_conduct/>. It is not copied here. It applies in the issue tracker, in pull requests, and anywhere else people speak for the project.

## Reporting

Report a problem privately through the repository's private reporting form: <https://github.com/maksim9980/the_nod/security/advisories/new>. The form is made for security reports, but it is the private channel the repository has; start the title with "Conduct:". Please do not report it in a public issue or pull request.

## What maintainers do with a report

A maintainer reads the report and keeps the reporter's name private. They look at what happened, then pick a response: a private conversation with the person, a warning, removing a comment or a contribution, or a temporary or permanent ban. The reporter is told what was decided.
