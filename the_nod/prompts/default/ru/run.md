Сделай шаг {step} «{step_title}» карточки «{title}» (`{card}`) в репе `{root}`.
Работай по брифу `{brief}`.

Сначала прочитай файл `{answers}`. В нём ответы владельца. Файла может не быть.
Опирайся на раздел 10 брифа и на решения из раздела 4.

Ты уже в корне репы: запускай команды из него, без `cd` и без `git -C`.
Список разрешений по умолчанию даёт Bash запускать эти команды, по одной за вызов: `git status`, `git status --short`, `git log --oneline -20`, `git log -5`, `git diff`, `git diff --stat`, `git diff --cached`, `git add <путь>`, `git commit -m "<сообщение>"`, `python -m pytest`, `python -m pytest <аргументы>`, `python3 -m pytest`, `python3 -m pytest <аргументы>`, `nod …`.
Файлы читай и ищи инструментами Read, Grep и Glob.
Отказ в команде не останавливает шаг: сделай то же разрешённой командой или инструментом.

Коммить в текущую ветку. Не делай push, не переключай ветку.
После каждого законченного куска запиши прогресс:
`nod --root "{root}" run progress {run} --contracts-done N`
Если запись не появляется 40 минут, ран остановят.

Внимание: строка `blocked` останавливает шаг.
Драйвер сам заведёт по ней решение `owner-action`.
Тогда свою команду `decision ask` не запускай: решений станет два.

Если шагу нужно то, что может дать только владелец, не гадай и не спрашивай в чате.
Только владелец даёт вход, ключ API, тестовую карту. Только владелец поднимает упавший стенд.
Если шаг нельзя продолжить без этого, запиши в `{result}` одну строку и остановись:
`blocked = "<что нужно от владельца, одной фразой>"`
Если шаг можно продолжать без этого, заведи решение сам:
`nod --root "{root}" decision ask --kind owner-action --card {card} --question "<что сделать владельцу>" --proposed done --option done --option postpone`
Команда печатает id решения. Запомни его.
Перед продолжением заблокированной работы прочитай решения командой:
`nod --root "{root}" decision list --all --json`
Найди решение по id.
Ответ `done` — владелец сделал; продолжай.
Ответ `postpone` — драйвер вернёт карточку в бэклог. К этой работе не возвращайся. Заверши шаг ответом «отложено владельцем».

Последним действием запиши в `{result}` TOML:
- `result = "ok"` или `result = "stop"`. Если шаг не удалось довести, пиши «stop».
- `contracts_total` — сколько кусков в шаге.
- `contracts_done` — сколько кусков сделано.
- `note` — одна фраза о том, что сделано или почему стоп.
В чат ответь одним словом.
